# Files excluded from GitHub

This document lists everything that must **never** be committed. The patterns live in `.gitignore` at the repository root. This file itself IS committed so everyone knows the rules.

## 1. Secrets and credentials (critical)

| Pattern | Why |
|---|---|
| `.env`, `.env.*` (except `.env.example`) | Contains `GROQ_API_KEY`, YouTube/Twitch keys, DB URLs |
| `*.pem`, `*.token`, `.credentials/`, `cookies*.txt` | Auth material / browser cookies |
| `client_secret*.json`, `*_token.json`, `.creds/` | OAuth tokens |
| `*.kdbx`, `*.key` | Key stores |

`.env.example` is the **only** env file that is committed — it contains placeholders, never real values.

## 2. Python / Node artifacts

| Pattern | Why |
|---|---|
| `.venv/`, `__pycache__/`, `*.py[cod]`, `*.egg-info/` | Generated by uv/Python |
| `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`, `coverage/`, `.coverage`, `htmlcov/` | Test/lint output |
| `dist/`, `build/` | Build output |
| `node_modules/`, `.next/`, `out/`, `*.tsbuildinfo`, `npm-debug.log*` | Frontend dependencies/build |

## 3. Generated media and transcripts

| Pattern | Why |
|---|---|
| `storage/sources/*`, `storage/clips/*`, `storage/thumbs/*`, `storage/captions/*`, `storage/exports/*` | Downloaded videos, rendered clips, thumbnails, transcripts |
| `*.mp4`, `*.mkv`, `*.mov`, `*.webm`, `*.m4v`, `*.part`, `*.ytdl` | Video files |
| `*.flac`, `*.wav`, `*.mp3` | Extracted audio |
| `*.srt`, `*.vtt`, `*.ass` | Generated captions |
| `*.info.json` | yt-dlp metadata dumps |
| `!storage/*/.gitkeep` | Exception: keep empty folders in the repo |

## 4. Local OS/editor files

`.DS_Store`, `Thumbs.db`, `.idea/`, `.vscode/`, `*.swp`, `*.log`

## What IS committed

- All `*.md` docs, `AGENTS.md`, `RULES.md`, `NO.md`, etc.
- `backend/`, `frontend/src/`, `frontend/package.json`, configs
- `.opencode/skills/` (agent instructions — part of the project)
- `.gitignore`, `.env.example`, `.python-version`, `uv.lock`, `pyproject.toml`
- `docker-compose.yml`, `Dockerfile`, `scripts/`

## Verification commands

```powershell
git status --short                 # files that WILL be committed
git status --short --ignored       # files excluded (marked !!)
git check-ignore -v <path>         # which rule ignores a path
```

Before pushing: `git diff --cached` must contain no keys, no `.env`, no media.
