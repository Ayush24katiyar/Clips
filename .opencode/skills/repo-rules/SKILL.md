# Repo Rules

Read the relevant file before editing code:

- `AGENTS.md` — commands, layout, verification, agent boundaries (always active).
- `RULES.md` — naming, layering, typing, tests, commits.
- `NO.md` — hard prohibitions. A violation is a bug.
- `OBJECTIVES.md` — product goals and acceptance criteria.
- `QUALITY.md` — CRF modes, resolution honesty, output validation, loudness.
- `ARCHITECTURE.md` — modules, pipeline, DB schema, extension points.
- `RESEARCH.md` — why we chose Groq and why selection beats effects.

Use the `ffmpeg-recipes`, `clip-pipeline`, and `groq-api` skills for domain-specific work.
